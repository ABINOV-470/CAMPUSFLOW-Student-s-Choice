# CampusFlow 🎓

**Your personal academic productivity and learning companion.**

CampusFlow is a student-focused platform designed to help learners organize their academic life, manage study schedules, track academic goals, prepare for exams, and explore career opportunities in one place.

## ✨ Features

- 📚 **Academic Dashboard** — Organize subjects and monitor academic progress.
- 📅 **Study Planner** — Manage study sessions, tasks, and deadlines.
- 🎯 **CGPA Goals** — Track current academic performance and target goals.
- 🤖 **AI Study Companion** — Get learning assistance and study recommendations, depending on configured AI integration.
- 💼 **Career Planning** — Explore career paths, skills, and project ideas.
- 📈 **Progress Tracking** — Monitor learning activities and completed tasks.
- 📱 **Responsive Design** — Access the platform across supported screen sizes.
